# animal.sh

Animal hierarchy shell helpers.

Demonstrates Bash functions, calls, and comments.

---

## `make_sound()`

```
make_sound()
```

Produce the characteristic animal sound.

### Returns

The sound text.

---

## `get_name()`

```
get_name()
```

Retrieve the animal name.

### Parameters

| Direction | Name | Type | Description |
|-----------|------|------|-------------|
| [in] | `name` | `` | Animal name. |

---

## `feed()`

```
feed()
```

Feed the animal.

### Parameters

| Direction | Name | Type | Description |
|-----------|------|------|-------------|
| [in] | `amount` | `` | Portion size in grams. |
